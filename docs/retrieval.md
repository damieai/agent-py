# 可追溯的上下文编译

当前提供两个本地检索策略，均在文档授权过滤之后排序，无外部 embedding 或模型调用。默认 `AGENT_CONTEXT_STRATEGY=lexical` 保留已有整篇词项召回；设置为 `bm25_rrf` 可启用分块及融合排序。API、Worker 和手动分析 CLI 应使用一致配置。

## 编译路径

1. 复核 Principal 的项目、环境及当前 Grant，任务查询额外复核 Task 范围。SQL 过滤租户、项目、任务绑定、撤回及有效时间，随后过滤文档 subject ACL。
2. 新策略对 Python 源使用 AST 顶层函数/类边界，包含装饰器；解析源不执行或导入模块。非 Python、语法错误及大于 64 KB 的源码使用行窗口。窗口目标 2400 字节，过长单行保持完整，由预算决定是否丢弃。嵌套方法不独立建符号索引。
3. 正文使用 BM25（`k1=1.2, b=0.75`，正值平滑 IDF）；来源路径和顶层符号使用查询词交集。两路非零匹配列表按 RRF `sum(1/(60+rank))` 融合，平分按文档 ID、行号稳定排序。它是两路稀疏检索，不是向量混合检索或交叉编码器重排。
4. 分词保留完整标识符并增加 snake/camel 组件；中文保留单字和连续二元词。不提供语义同义词、词干化或通用中文分词模型。
5. 按排名顺序贪心装入预算，过大片段记录为 omitted 后继续尝试后续片段。每个选中项保存来源、版本、整篇摘要、片段身份、精确正文、起止行、符号及两路排名。

排名参数参考 [Stanford IR 教材的 BM25](https://nlp.stanford.edu/IR-book/html/htmledition/okapi-bm25-a-non-binary-model-1.html) 与 [Cormack 等人的 RRF 论文](https://cormack.uwaterloo.ca/cormacksigir09-rrf.pdf)。这些算法的既有研究结果不等于本项目的效果保证；本实现选择和参数固定在 `context-v2-bm25-rrf` 策略版本中。

## 证据身份与失效

片段保留原 Document ID 供现有模型引用协议使用，另附 chunk ID 与行号定位。因此模型引用仍是文档级，不表示模型已经证明某一行支持其结论。代码源码快照和检索证据继续分开管理。

调用前及分析发布前重新检查当前授权、有效期、版本、来源、正文和片段边界。整篇任何位置变化都会使旧片段失效，包括未选中部分；验证不接受只改写正文后重新计算 bundle 摘要的伪造片段。原文撤权与网络请求之间仍有竞态窗口，不能撤回已经发给模型的内容。

候选修复继续使用已经冻结的 bundle 策略，切换默认配置不会重新编译旧快照。只读调查会重建上下文；推理已开始后切换策略或改变证据，现有推理账本将拒绝用原身份提交变化后的请求。应排空旧调查或新建任务，不要清除账本来强制重发。实现保留 v1 校验兼容性，不自动重写已有产物。

查询范围最多允许 1000 篇可读文档、合计 5 MB 正文和 10000 个片段；超过门槛返回 `CONTEXT_CAPACITY`，不会静默截取任意前 N 篇。当前逐次流式读取、内存排序，没有增量索引或缓存；ACL 不可读文档不进入词频、排名和 omitted，但扫描成本仍需容量测试。原有无任务绑定的文档按项目与 subject 共享，没有新增环境级文档 ACL。

历史字段 `estimated_tokens` 保持兼容，实际记录选中项 JSON 的 UTF-8 字节和，是文本 token 的保守估计，不是供应商 tokenizer 结果。budget 不包含整个请求的系统提示、omitted 列表和外层序列化；模型请求仍由独立预算账本控制费用。

## 使用与对照

```bash
# 仅对准备采用新策略的进程启用
export AGENT_CONTEXT_STRATEGY=bm25_rrf
.venv/bin/agent-py context-preview TASK_ID --query 'worker capacity' --budget 6000
.venv/bin/agent-py evaluate-retrieval examples/retrieval-development.json
```

工作台任务详情中的“查看当前可用证据”调用 `POST /api/v1/tasks/{id}/context/preview`。请求为 `{"query":null,"budget":6000}`，空 query 使用任务目标；不修改任务、不调用模型、不触发采集。接口使用当前用户文档 ACL，可能与任务发起人或旧快照看到的证据不同。响应 `Cache-Control: no-store`，源码仅作为 React 文本渲染，不执行、不自动打开来源链接。当前预览是一次快照，刷新时才重新鉴权，尚未做浏览器 E2E 验收。

离线评测在临时 SQLite 数据库执行真实编译路径，比较无检索、整篇词项、新策略；输出固定数据摘要、逐查询文档级 recall/precision/MRR、入选字节数和片段数。相同查询使用相同预算，不访问生产数据库、模型或网络。

随仓库的 12 个手写开发查询覆盖租约、预算、RLS、CI、回滚、中文队列、授权、Webhook、SSE、标识符、长源码及来源路径。当前结果为：无检索 recall/MRR 0；lexical 0.833/0.833；bm25_rrf 1.000/1.000。这是开发用例回归，不是独立 holdout，也不证明答案质量或生产泛化。后续应使用真实脱敏相关性标注，增加片段充分性、不同预算和真实答案质量评测，再决定默认策略。

待实现：向量召回、学习重排、多语言 AST、双时态知识、依赖图与缓存失效传播。此阶段不把这些计划项计入已交付能力。
